# 正方教务抢课助手

专门针对正方教务系统开发的自动选课脚本，主打「退课捡漏」场景。热门选修课秒没之后，不用一直守在电脑前手动刷新，脚本自动轮询课程列表，一旦检测到有人退课释放名额，自动完成选课操作。

## 开发初衷
每次选课季热门公选课几分钟就被抢空，后续虽然有人退课，但手动刷新很难刚好赶上名额释放的时间点。写这个脚本就是为了解放双手，自动蹲守捡漏，适合课没选满、想补抢热门课的同学用。

## 适用范围
- 适配正方教务系统通用课程面板结构
- 已适配：自主选课页面
- 其他使用正方教务的高校，可自行调整DOM选择器适配

## 核心功能
- **精准课程识别**：基于页面DOM结构提取课程代码、名称、学分、选课状态，识别稳定，不受文本换行、排版变化影响
- **自动轮询捡漏**：按设定间隔自动刷新课程列表，检测到可选课程自动提交选课
- **弹窗自动处理**：自动确认选课提示、成功弹窗；遇到退选类弹窗自动点取消，防止误操作退课
- **可视化控制面板**：页面悬浮操作面板，一键启停，实时查看运行轮次、成功/失败统计，新手也能快速上手
- **安全保护机制**：已选课程自动跳过，选课成功的课程不再重复操作，从逻辑上避免误点退选
- **随机延时波动**：默认开启随机间隔偏移，避免固定频率请求，降低被系统检测的风险

## 使用方法

### 方式一：控制台临时运行（无需装插件，临时用推荐）
1. **进入选课页面并筛选**
   登录正方教务系统，进入「自主选课」页面。
   > **重要：** 先在页面筛选条件里，将「有无余量」选择为「有」，让列表只显示有余量的课程。这步必做，否则脚本遍历效率会很低。

2. **打开开发者控制台**
   按 `F12` 键（或者右键页面 → 检查）打开开发者工具，切换到「Console / 控制台」标签。

3. **粘贴运行脚本**
   复制完整的脚本代码，粘贴到控制台输入框，按回车键运行。
   > 如果浏览器弹出粘贴安全提示，按提示输入对应指令允许粘贴即可。

4. **开始运行**
   页面右侧会弹出控制面板，点击「开始」即可自动运行。

### 方式二：油猴安装（长期用推荐）
1. 浏览器安装 Tampermonkey（油猴）插件
2. 新建脚本，清空默认模板，粘贴全部代码后保存
3. 打开正方选课页面，面板会自动加载，点击开始即可使用

## 配置说明
面板上可直接调整常用参数：
- 仅抢超星课：只处理名称包含「超星」的课程
- 超星优先：排序时超星课程排在前面，优先抢
- 失败重试：本轮选课失败的课程，下一轮继续尝试
- 间隔：每轮查询的基础间隔时间，单位毫秒，**建议不低于 2000ms**

## 注意事项
1. 本脚本仅用于前端技术学习交流，请勿用于恶意刷课、批量抢课等违反学校规定的行为
2. 间隔时间不建议设置过低，高频请求可能触发系统风控，导致账号功能受限
3. 脚本运行期间尽量不要手动操作课程列表，避免元素状态冲突
4. 脚本仅在「自主选课」页面生效，其他页面无法识别课程
5. 用完刷新页面即可关闭脚本

## 常见问题
**Q：运行后识别不到课程怎么办？**
A：先确认在自主选课页面，并且手动点过一次「查询」加载出了课程列表；如果是其他学校的正方系统，需要对应调整课程解析的DOM选择器。

**Q：点击选课后没反应？**
A：检查课程能否正常展开、选课按钮是否可见；部分课程选课时间未到、或者选课通道已关闭，会导致按钮不可用。

**Q：会不会被学校检测到？**
A：脚本本质是模拟人工点击操作，正常间隔下和手动操作行为接近；但不保证零风险，不建议设置过快的轮询频率。
